# Security policy

## Supported versions

Security fixes are shipped on the latest stable GitHub Release. Consumers should pin an immutable `vX.Y.Z` tag and keep the resolved lockfile commit aligned with that tag.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email `info@ai-created.com` with a concise description, affected component or release, reproduction steps, and any known impact.

Do not include production credentials, personal data, or unrelated private material. You can expect an acknowledgement within five business days. Confirmed issues will be fixed forward in a new immutable release; published tags are never moved.
